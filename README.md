# UED100 Assessment 2 — Qantas-inspired UI prototype

Educational prototype, **not affiliated with Qantas**. Flight prices, timetables, bookings, and points are simulated. No real bookings or payments are made.

## Local development
Open `index.html` in Visual Studio Code and launch with Live Server (or use `python3 -m http.server 5500`). The site uses local HTML, CSS, and JavaScript.

## Design
[Editable Figma wireframes — desktop and mobile](https://www.figma.com/design/DKzlLN9UVIOio3WbTKYgqR).

## Key features
- Mobile-friendly responsive flight search and navigation
- Cash versus Qantas Points fare presentation
- Four-stage booking progress, simulated fares, validation and review
- Pre-expiry session warning demo; accessible, keyboard-friendly messages
- Familiar Qantas task shortcuts and reduced promotional emphasis
- Contact form demonstration, original SVG multimedia artwork


## Privacy and scope
Use fictional details only. No server, payments, authentication or actual airline APIs are connected. Client-side validation is for usability, not server-side security.
