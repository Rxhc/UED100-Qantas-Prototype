# Usability testing — UED100 Qantas prototype

**Status: Not conducted yet.** This is a template to populate using actual participant observations.

## Objectives
Evaluate whether leisure travellers and frequent flyers can search for a flight, understand the cash/points option, follow the booking steps, recover from form errors, and navigate on mobile.

## Procedure
Recruit 3–5 volunteers (or the number required by the marking rubric). Ask each person to attempt tasks without guidance. Explain this is a student demonstration: no real bookings or payments happen. Ask permission before recording. Avoid collecting real personal details.

## Tasks
1. Find and search for a return Sydney–Melbourne flight.
2. Switch the fare display between AUD cash and Qantas Points.
3. Choose a sample flight and proceed to passenger details.
4. Trigger a validation error and describe how to fix it.
5. Complete the simulated booking and identify the progress indicator.
6. Navigate the interface at a narrow mobile viewport.
